# 信标模组

`scnet.beacon` 提供半格高的电力信标，为夜间探索提供方向标记。

## 使用

- 创造物品栏的电气分类中只有一种信标物品。
- 放在实体支撑方块上，使用地面导线连接电池、开关等电源。接线方式与电池、圣诞树等地面电器一致，底座四周接受输入。
- 断电熄灭。输入电压从零到满档，对应亮度 0–15；多个输入取最高值。亮度同时影响附近照明、光源和光柱。
- 点击交互轮换八种颜色。半球光源和光柱亮芯偏白，外层光柱保持所选色。没有内置开关或 G 编辑面板。
- 挖掘后颜色和供电状态重置，回收物品可正常堆叠。再次放置时从冰蓝色、未供电状态开始。
- 光柱沿半球轮廓向上延伸至高度 1024，被上方不透明方块截断。只渲染已加载区块中的信标，最远水平距离为 512 格。
- 光柱不沿整条路径投射地形照明，也没有传送或增益作用。

配方产出一个信标：

| 玻璃 | 玻璃 | 玻璃 |
| --- | --- | --- |
| 玻璃 | 电灯 | 玻璃 |
| 铁锭 | 铁锭 | 铁锭 |

开关或电池作为外部供电装置，不消耗在信标配方中。

## 开发与导入

按解决方案构建说明准备本地 NuGet 依赖，然后运行：

```bash
dotnet build BeaconMod/BeaconMod.csproj
```

模组使用 `SCNET.Survivalcraft` 与 `SCNET.ContentTool` NuGet 包，构建生成
`bin/Debug/net10.0/packages/scnet.beacon.scpkg`。通过游戏文件导入后加入全局或世界模组配置；联机双方须加载相同的包。

`Resources/Models/Beacon.scad` 为建模源文件，GLB 为游戏模型。
模型由薄底座、玻璃罩和半球光源组成；修改后使用标准 glTF 2.0 导出器重新导出 GLB，保留部件名称 `base`、`glass`、`core` 和纹理坐标。
电路通过内置 `IElectricElementBlock` 与 `ElectricBlockBehavior` 接入，交互、仿真和同步沿用游戏现有流程。
颜色和亮度保存在放置方块的数据位中，物品数据统一为零。
